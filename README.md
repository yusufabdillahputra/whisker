# Whisker

Knowledge base terpusat (second brain lintas device dan lintas proyek) dengan Flutter, Serverpod, dan
Forui, terinspirasi dari [Hubzoid](https://github.com/hubzoid/hubzoid). Agent AI mengaksesnya lewat MCP
dengan plugin di [`whisker-plugins`](https://github.com/yusufabdillahputra/whisker-plugins).

> **Status: pra-implementasi.** Mulai dari [`CLAUDE.md`](CLAUDE.md) dan folder [`Guides/`](Guides/).

Target platform: Android, iOS, Web, macOS, Windows, Linux.
